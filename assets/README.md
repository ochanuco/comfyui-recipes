# Yukari data assets

Everything in this directory belongs to the Yuzuki Yukari workflow:

- `delivery-fingerprint.json` is the accepted fingerprint of the delivery
  identity, checked by `scripts/delivery_check.py`.
- `fonts/BarlowCondensed-SemiBold.ttf` is the viewfinder overlay's typeface,
  under the SIL Open Font License (`fonts/OFL.txt`).

There are no other character profiles or character data sets here.
