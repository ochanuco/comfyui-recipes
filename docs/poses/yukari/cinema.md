# cinema

一緒に映画を観に行くゆかりさん. Walking with a popcorn bucket in one hand
and a straw cup in the other, in a movie theater, full body on the 832x1664
canvas.

```
(solo:1.5), (walking:1.3), (from front:1.2), (holding popcorn:1.45),
(popcorn:1.4), (holding cup:1.4), (disposable cup:1.3),
(drinking straw:1.45), (movie theater:1.4), (indoors:1.2), (full body:1.45)
```

The pose exists on this recipe as the control for `yukari-anima`'s
`cinema`: the same subject rendered by both checkpoints and finalized the
same way. The IL render (uulwyu) reads far less like AI output than the
Anima one (a4bdvy) -- line, face and finish move together -- which places
the AI look with the Anima base rather than with the theme. See
`experiments/yukari/cinema.jsonl`.
